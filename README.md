# CareBrief

A local administrative appointment organiser. Open index.html in a browser; it has no dependencies and makes no application network requests.

Features: fictional demo, visit/date entry, prioritized questions, discussed-question tracking, exact-copy notes, text export and print/PDF. Data stays in page memory and clears on reload.



Project: https://devpost.com/software/carebrief
Demo: https://youtu.be/FNJncNJNXW0

The attached submission package includes this interactive prototype, a one-page project PDF and a complete code PDF. The demo shows actual prototype interactions with synthesised narration. Use fictional data for demonstration, and review any exported brief before sharing it.

## Source code and how to run it

- **Complete application source:** [index.html](./index.html). This single file includes the HTML interface, CSS styling, and JavaScript logic inside its `<script>` section. The PDFs are supporting documents; they are not required to run the application.
- **Run locally:** choose **Code → Download ZIP**, extract the ZIP, and open `index.html` in a browser. No install, server, API key or build step is needed.
- GitHub's file view displays source text; it does not run the application. The **Raw** or **Download raw file** control provides the complete source file.
