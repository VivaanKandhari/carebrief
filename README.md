# CareBrief

A local administrative appointment organizer submitted to DSH Hacks V2 on 14 October 2026. Open index.html in a browser; it has no dependencies and makes no application network requests.

Features: fictional demo, visit/date entry, prioritized questions, discussed-question tracking, exact-copy notes, text export and print/PDF. Data stays in page memory and clears on reload.

Codex generated the implementation and submission materials. This deterministic prototype performs no model inference, diagnosis or treatment advice. No patient research or clinical validation is claimed.

Project: https://devpost.com/software/carebrief
Demo: https://youtu.be/FNJncNJNXW0

The attached submission package includes this interactive prototype, a one-page project PDF and complete code PDF. The demo shows actual prototype interactions with synthesized narration. Use fictional data for demonstration and review any exported brief before sharing it.
